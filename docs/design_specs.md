# GOMIKIN DESIGN SPECIFICATION

Design version:
Alternative Embodiment B

Status:
Prototype / dimensions still being finalized

## Coordinate system

X = left/right
Y = vertical
Z = front/back

Front = +Z

## Current confirmed dimensions

Input section:
200 mm

Divider height:
700 mm

## Geometry rules

- Do not invent dimensions.
- Preserve proportions from reference sketches.
- Components must remain separate objects.
- Moving components must have independent pivots.
- Components requiring future simulation must have collision-friendly geometry.
