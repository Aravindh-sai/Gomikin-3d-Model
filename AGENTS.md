# Workspace Guidelines & Rules

## 1. Git Commit Attribution
- Always commit using the user's personal Git account (`Abhinav087 <hifiabhinav087@gmail.com>`).
- Never use bot accounts or AI agent placeholders for author attribution.
- Use `--author="Abhinav087 <hifiabhinav087@gmail.com>"` or configure user identity directly.

## 2. Frequent Checkpoint Commits
- Commit after every major feature, fix, or architectural implementation.
- Maintain clean atomic commits with descriptive conventional commit messages so the team can revert to any given checkpoint safely.

## 3. Project Context Tracking
- After every change, update `CONTEXT.md` to keep documentation synchronized with codebase evolution.
